07 / Switch Zyxel

Ports ACCESS & TRUNK
la base du 802.1Q

🔌 PORT ACCESS
Un port = un VLAN. Connecte un équipement final (PC, imprimante, AP). Les trames sortent non taggées : l'équipement ne voit pas le VLAN.
🖥️
🔀
1 couleur = 1 VLAN
🔗 PORT TRUNK (802.1Q)
Un port = plusieurs VLANs. Relie deux équipements réseau (firewall, switch, hyperviseur). Les trames conservent leur tag VLAN.

13 / Retours d'Expérience

Difficultés rencontrées
= compétences acquises

🔌 ACCESS vs TRUNK Comprendre la différence entre un port mono-VLAN (untagged) et un port multi-VLAN taggé 802.1Q. → Maîtrise du switch administrable.
🧱 Sous-interfaces VLAN sur Sophos ACLs des services locaux, ICMP vers passerelles, association zone + VLAN ID + DHCP. → Diagnostic via logs firewall.
💾 VLAN Tags dans VMware ESXi Port Groups, vSwitch en TRUNK, correspondance exacte du VLAN ID avec switch et Sophos. → Intégration physique / virtuel.
📋 Ordre des règles firewall Les règles sont lues de haut en bas, première règle correspondante = appliquée. → Pensée logique du filtrage réseau.
💡
L'enseignement principal : une infrastructure réseau, ce n'est pas chaque équipement pris séparément — c'est la cohérence entre eux. Le switch, le firewall et l'hyperviseur doivent parler le même langage VLAN pour que tout fonctionne.
À retenir

5 idées clés
en synthèse

1
Le Sophos est le point central de sécurité. Firewall · NAT · DHCP · Routage inter-VLAN · Journalisation
2
Les VLANs séparent les profils. ADMIN · PEDA · ELEVE — un /24 par profil, une passerelle dédiée
3
Le switch Zyxel transporte les VLANs. Ports ACCESS pour les postes · TRUNK 802.1Q vers Sophos et ESXi
4
ESXi permet de simuler les utilisateurs. 3 VMs dans 3 Port Groups VLAN, un seul serveur physique
5
Les tests prouvent l'isolation. ipconfig · ping passerelle · isolation inter-VLAN · logs Sophos
