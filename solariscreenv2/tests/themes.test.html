SOLARISCREEN — Tests des thèmes

Un thème n'est pas qu'une affaire de goût : ici la couleur porte du sens — le liseré dit l'ACTION, la pastille dit le CLIENT, le badge dit le STATUT. Ces tests mesurent, pour chaque thème déclaré dans SSTheme.THEMES, que les textes restent lisibles et que les familles d'action restent séparables. Un thème qui n'y passe pas ne se publie pas, même s'il est beau.
