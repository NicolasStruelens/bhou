SOLARISCREEN — Tests du bac à sable

Le bac à sable remplit la base d'ESSAI des aperçus de branche (DEPLOIEMENT.md, étape 12). Ces tests le jouent contre le VRAI fichier du serveur (functions/api/[[catchall]].js) branché sur une vraie base SQLite en mémoire (sql.js, chargé depuis cdnjs), par les mêmes fonctions SS.* que les écrans : gardes, remplissage, rejouabilité, montants, actions reconnues par le tableau de bord, page de remplissage, vidage.

⚠️ À ouvrir PAR LE SERVEUR DE TEST (et avec un accès à cdnjs). Aucune donnée réelle : la base vit dans la page et disparaît avec elle ; les caches locaux du navigateur sont remis en état à la fin.
